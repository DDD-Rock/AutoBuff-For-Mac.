# RapidOCR resources

The macOS EXP reader bundles the unmodified PP-OCRv4 detection and recognition
ONNX models plus the PaddleOCR recognition dictionary used by the Windows
client. They originate from PaddleOCR/RapidOCR and are distributed under the
Apache License 2.0. See `LICENSE-PaddleOCR.txt`.

Inference uses the unmodified ONNX Runtime 1.23.2 universal macOS library.
See `LICENSE-ONNXRuntime.txt` and `THIRD_PARTY_NOTICES-ONNXRuntime.txt`.

No bundled OCR runtime or model has been trained or modified by this project.
